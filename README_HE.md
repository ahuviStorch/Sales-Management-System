# גרסה 4 — קופת מכירה למוצרי אפייה

המערכת והתיעוד בעברית מלאה, בכיווניות RTL.

## הפעלה

1. יש לפתוח את התיקייה ב־VS Code.
2. להריץ `npm install` אם התלויות עדיין אינן מותקנות.
3. להריץ `npm run dev`.

## מה שונה

- במסך תשלום: סכום גדול וכפתור אישור וסיום צמודים, בחלק עליון דביק.
- במסך עגלה: סכום וכפתור מעבר לתשלום צמודים.
- קובץ CSS נכתב מחדש במקום הוספת דריסות.
- קיים אפיון מוצר מפורט בעברית וקובץ הנחיות באנגלית להעברה לכלי פיתוח.

## מגבלות

זהו אב־טיפוס בלבד. נתונים נמחקים ברענון; אין סליקה אמיתית, שרת, הרשאות, מלאי או דוחות מלאים. חלק מדרישות האפיון עדיין לא מומשו. אין לטעון שנבדק בדפדפן עד שמבצעים בדיקה כזאת.

## עדכון אפיון 4.1

הדרישה המעודכנת: מסך הצלחת תשלום מוצג 4 שניות ואז מעבר אוטומטי למכירה חדשה. זהו עדכון תיעוד בלבד; הקוד הקיים לא שונה.
